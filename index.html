Engine Architecture

Built for Speed, Reliability & Precision

Engineered directly on Windows Win32 APIs for instantaneous hardware response without system overhead.

🛡️

Single-Instance Mutex Guard

Features Kernel32 Mutex guard (`CreateMutexW`). Guarantees zero duplicate launches by restoring and bringing the existing instance to focus immediately.

🖥️

Win32 DDC/CI Hardware Engine

Communicates over `dxva2.dll` to read and write physical monitor hardware registers directly via VCP code `0x10` (Brightness) and `0x12` (Contrast).

🔄

Selective Display Unlinking

Toggle sync on or off at will. Individually tweak independent monitors or lock them all together to your master laptop brightness key.

⚡

Non-Blocking Debounced Queue

Executes hardware writes on a dedicated `QThread` with a 120ms trailing-edge debounce worker. Slider movement stays buttery smooth without lag.

🎛️

Win11 Quick Control Flyout

Single-click or tap on the system tray icon pops up an Action Center styled floating slider menu right above the Windows taskbar for instant tweaks.

🔌

Hot-Plug & JSON State Persistence

Automatically detects monitors plugged in or disconnected on the fly via `WM_DISPLAYCHANGE` while persisting preferences safely to local storage.
